Write the file `/app/summary.md` as a short status note with exactly
this structure:

- The first line is `# Summary`.
- Later, in this order: a `## Findings` heading, then a
  `## Next steps` heading.
- Every heading is followed by at least one non-empty line.
- No line has trailing whitespace; the file ends with one newline.

The content under the headings is up to you — structure is graded,
prose is not.

Commit your work with git when done.
